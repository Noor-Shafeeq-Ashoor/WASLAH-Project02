# WASLAH — Project 02

WASLAH is a career and professional development platform designed for **students, graduates, job seekers, and freelancers in Bahrain**.

The main idea is to bring **job opportunities, skill development, networking, and professional services** together in one platform. Instead of using separate platforms for finding jobs, developing skills, and connecting with employers, users can access these services through WASLAH.

## 📌 About the Project

WASLAH allows users to create accounts and build professional profiles based on their skills and interests. Users can search for job opportunities, apply for suitable positions, and participate in courses that can help them develop new skills.

Employers can create and manage job opportunities and review applications from users. The platform also supports communication and notifications to help users and employers stay updated about important activities.

WASLAH also includes **workspace and study-space reservations through partner locations**, giving users the option to reserve suitable places for studying, working, or professional activities.

The application includes authentication, authorization, email verification, password management, file uploads, and other security features to protect user accounts and information.

## ✨ Main Features

* 👤 User registration, email verification, and login
* 🔐 JWT authentication and role-based authorization
* 📝 User profiles with profile picture upload
* 💼 Job opportunity creation, search, filtering, and applications
* 📩 Job application management and status updates
* 📚 Courses and skill development
* 🤝 Communication between users and employers
* 🏢 Study and workspace management
* 📅 Workspace reservation and availability management
* 🚫 Double-booking prevention
* 🔔 Real-time notifications for important activities
* 📧 Automated email notifications
* 💳 Payment support for selected services
* 🛡️ Secure handling of user information
* 📋 Audit logging for important actions

## 🎯 Project Goal

The goal of WASLAH is to provide a **single platform for career opportunities, professional development, networking, and workspace access**.

The platform is designed around the needs of students, graduates, job seekers, freelancers, and employers in Bahrain, while providing a secure and organized backend for managing users, opportunities, applications, courses, reservations, and notifications.

## 🛠️ Technical Scope

WASLAH is developed using:

* **Java**
* **Spring Boot**
* **Spring Security**
* **JWT**
* **PostgreSQL**
* **REST APIs**
* **WebSocket / Server-Sent Events**
* **Swagger / OpenAPI**
* **Git & GitHub**

The application follows a layered architecture consisting of **Controllers, Services, Repositories, DTOs, and Entities**, with validation, exception handling, logging, testing, and database seeding.
